# SIMULATOR-CONTROLLER-PID-FOR-DC-MOTOR
Simulador de control PID y control real de velocidad para un motor DC. App de escritorio en Python (PyQt5) que resuelve el modelo del motor con RK4, y firmware en Arduino Uno que mide RPM con un encoder óptico FC-03 y regula el PWM con un PID discreto con prealimentación y anti-windup. Proyecto de Control Inteligente.
